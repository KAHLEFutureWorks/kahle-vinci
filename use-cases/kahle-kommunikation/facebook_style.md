# facebook_style.md

## 1) Master-Stil Kurzprofil
Facebook ist euer **lokaler Vertrauenskanal + Community-Layer** (Hannover/Niedersachsen) und Retargeting-Fläche. Fokus: **Service-Posts**, **Events**, **Sprechstunden**, **Messenger-CTAs**.

## 2) Prinzipien
- Nutzen in den ersten 2 Zeilen.
- Lokaler Kontext erhöht Relevanz.
- Events/Anmeldungen sind Conversion-Hebel.
- Kurze Texte + klarer CTA.
- Kommentare schnell beantworten.

## 3) Blueprints
- **Mini-Case:** Nutzen → 3 Schritte → Proof → CTA (Messenger)
- **Event/Webinar:** Problem → Agenda → Für wen → CTA (Anmeldung)
- **Checkliste/Download:** Value → Inhalt → CTA + DSGVO-Hinweis
- **Myth-Busting:** Myth → Reality → Steps → Disclaimer → CTA

## 4) Hook-Bibliothek (25)
1. „KMU in Hannover: KI sauber starten – ohne Chaos.“
2. „Kostenlose KI-Sprechstunde (30 Min): 3 Slots diese Woche.“
3. „Wenn KI im Team ‘wild’ genutzt wird: so holst du Kontrolle zurück.“
4. „3 Prozesse, die KMU sofort entlasten können.“
5. „Datenschutz & KI: was du organisatorisch heute tun kannst.“
6. „Pilot statt Großprojekt: so geht’s in 14 Tagen.“
7. „KI bringt nichts? Dann fehlt meist ein Workflow-Standard.“
8. „Vorlage gratis: Use-Case-Karte für KMU.“
9. „Checkliste: Was nicht in KI-Tools gehört.“
10. „Webinar: KI ohne Hype – mit Templates.“

## 5) CTA-Bibliothek (15)
- „Schreib uns ‘CHECK’ im Messenger – wir senden die PDF.“
- „Kommentar ‘LINK’ für Download.“
- „Anmeldung über Link.“
- „Kurze Nachricht für Terminvorschlag.“
- „Newsletter: 1×/Monat, Abmeldung jederzeit.“

## 6) Proof / Einwände / Format
- Proof: Pilot klein (1 Team/1 Prozess/1 KPI).
- Einwand: Datenschutz → Datenklassen + DPA + Regeln (keine Rechtsberatung).
- Format: 80–180 Wörter + Visual + CTA.


**Compliance-Guardrails (immer):**
- Keine Fake-Scarcity („nur heute”, „letzte Plätze”) ohne belegbaren Grund.
- Keine irreführenden Leistungsversprechen (keine Garantie auf Umsatz/Erfolg).
- Keine implizite Rechtsberatung; bei DSGVO/EU AI Act: „keine Rechtsberatung” + Verweis auf DSB/Anwalt.
- Datenminimierung: keine personenbezogenen Details/Case-Infos ohne Freigabe.
- Transparent: „Beispiel/Schätzung” klar kennzeichnen; Zahlen nur mit Kontext.
