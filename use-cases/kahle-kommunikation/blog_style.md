# blog_style.md

## 1) Master-Stil Kurzprofil
Der Blog ist euer **SEO- und Authority-Kanal**. Lead-Engine über: klare Suchintention, Frameworks, Beispiele, Templates, und CTAs (Download, Termin, Newsletter). Stil: fachlich, verständlich.

## 2) Prinzipien
- Problem + Outcome + Zielgruppe in den ersten 150 Wörtern.
- H2-Struktur + Scannability.
- Templates/Checklisten als Differenzierung.
- Einwände + Risiken + Compliance als eigener Abschnitt (keine Rechtsberatung).
- CTA: oben (soft), Mitte (Asset), unten (Termin).

## 3) Artikel-Blueprints
- **Case Study:** Kontext → Problem → Lösung → Ergebnis → Learnings → Template → CTA
- **How-to:** 14‑Tage‑Plan → Rollen → KPIs → Templates → CTA
- **Myth-Busting:** Mythen → Einordnung → Maßnahmen → Disclaimer → CTA
- **Offer/Lead Magnet:** Inhalt → Nutzen → Anleitung → Download → CTA

## 4) Hook-Bibliothek (25)
1. „Der 14‑Tage‑Plan, um KI im KMU messbar zu machen.“
2. „Use-Case-Priorisierung: Framework + Vorlage.“
3. „DSGVO und KI: organisatorisch möglich – ohne Risiko-Hype.“
4. „Warum Prompting ohne Workflow-Design scheitert.“
5. „Die kleinste Governance, die funktioniert.“
6. „Welche KPIs für KI-Projekte im Mittelstand Sinn ergeben.“
7. „Welche Daten nie in öffentliche KI-Tools gehören.“
8. „Von 0 auf Pilot: Setup in 2 Wochen.“

## 5) CTA-Bibliothek
- „Download (PDF): Use-Case-Karte + Priorisierungsbogen.“
- „Termin: 30‑Min Erstgespräch.“
- „Newsletter: 1×/Monat, Abmeldung jederzeit.“
- „Webinar: Anmeldung.“


**Compliance-Guardrails (immer):**
- Keine Fake-Scarcity („nur heute”, „letzte Plätze”) ohne belegbaren Grund.
- Keine irreführenden Leistungsversprechen (keine Garantie auf Umsatz/Erfolg).
- Keine implizite Rechtsberatung; bei DSGVO/EU AI Act: „keine Rechtsberatung” + Verweis auf DSB/Anwalt.
- Datenminimierung: keine personenbezogenen Details/Case-Infos ohne Freigabe.
- Transparent: „Beispiel/Schätzung” klar kennzeichnen; Zahlen nur mit Kontext.
